Papel 0.1.2: Papel vuelve a hablar tu idioma en Linux y Windows, y la búsqueda de actualizaciones ya no falla con «http status: 403».

*Papel 0.1.2: Papel speaks your language again on Linux and Windows, and checking for updates no longer fails with "http status: 403".*

## Español

### Correcciones

- Los paquetes de Linux y Windows de 0.1.0 salieron solo en inglés porque se compilaron sin las traducciones. Ahora se compilan siempre con ellas, y la compilación falla si faltan, así que no puede volver a pasar sin que nadie se entere. Los de macOS ya las traían.
- Buscar actualizaciones ya no termina en «Could not reach GitHub Releases: http status: 403». GitHub solo responde unas pocas consultas por hora desde cada red, compartidas por todas las apps que la usan. Ahora Papel guarda la última lista de versiones y, al volver a buscar, solo pregunta si ha cambiado, una pregunta que no gasta ese límite.
- Si el límite se agota igualmente, Papel sigue sabiendo cuál es la versión más nueva y ofrece abrir su página. Si no puede saberlo, explica en tu idioma qué ha pasado y cuándo volver a intentarlo.
- Descargar una actualización ya no se corta a mitad (por ejemplo al 75 %) con «timeout: receive body». Solo se detiene si la conexión deja de responder, y al reintentar sigue desde donde iba.
- Las sumas de comprobación de macOS (`SHA256SUMS-macos`) ahora se publican junto al resto de archivos de la versión.

### Notas

- No existe un Papel 0.1.1 publicado: esta versión lo sustituye y reúne sus cambios.

## English

### Fixes

- The Linux and Windows packages of 0.1.0 came out in English only because they were built without the translations. They are now always built with them, and the build fails if they are missing, so this cannot happen again unnoticed. The macOS ones already had them.
- Checking for updates no longer ends in "Could not reach GitHub Releases: http status: 403". GitHub answers only a few requests an hour from each network, shared by every app on it. Papel now keeps the last list of releases and, when it checks again, only asks whether it changed, a question that does not spend that limit.
- If the limit runs out anyway, Papel still knows which version is newest and offers to open its page. If it cannot tell, it says in your language what happened and when to try again.
- Downloading an update no longer stops part way (at 75 %, say) with "timeout: receive body". It stops only if the connection stops responding, and a retry carries on from where it was.
- The macOS checksums (`SHA256SUMS-macos`) are now published with the rest of the release's files.

### Notes

- There is no published Papel 0.1.1: this version replaces it and carries its changes.
